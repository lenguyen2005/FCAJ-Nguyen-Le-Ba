* Get familiar with AWS database systems.

### Achievements in Week 3:

- Understood the role of **Amazon Relational Database Service (RDS)** in providing managed relational database services on AWS.

- Grasped the database management systems supported by Amazon RDS:
  - MySQL
  - PostgreSQL
  - MariaDB
  - Microsoft SQL Server
  - Oracle Database

- Understood the basic components and concepts of Amazon RDS:
  - DB Instance
  - Storage
  - Backup & Snapshot
  - Multi-AZ Deployment
  - Read Replica
  - Security Group

- Learned how to create and configure an **Amazon RDS Instance** via the AWS Management Console.

- Understood the process of connecting applications or Amazon EC2 to Amazon RDS via VPC and Security Groups.

- Understood the advantages of Amazon RDS compared to self-managed databases on EC2:
  - Automated Backup
  - Patch Management
  - Scalability
  - High Availability

- Learned about **Amazon DynamoDB** and the NoSQL database model on AWS.

- Grasped the basic concepts of Amazon DynamoDB:
  - Table
  - Item
  - Attribute
  - Partition Key
  - Sort Key

- Learned how to create and manage tables in Amazon DynamoDB.
- Understood the differences between relational databases (Amazon RDS) and NoSQL databases (Amazon DynamoDB), thereby knowing how to choose the right service for each use case.
