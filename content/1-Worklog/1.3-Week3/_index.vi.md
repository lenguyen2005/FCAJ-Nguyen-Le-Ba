### Kết quả đạt được tuần 3:

- Hiểu được vai trò của **Amazon Relational Database Service (RDS)** trong việc cung cấp dịch vụ cơ sở dữ liệu quan hệ được quản lý trên AWS.

- Nắm được các hệ quản trị cơ sở dữ liệu mà Amazon RDS hỗ trợ:
  - MySQL
  - PostgreSQL
  - MariaDB
  - Microsoft SQL Server
  - Oracle Database

- Hiểu các thành phần và khái niệm cơ bản của Amazon RDS:
  - DB Instance
  - Storage
  - Backup & Snapshot
  - Multi-AZ Deployment
  - Read Replica
  - Security Group

- Biết cách tạo và cấu hình một **Amazon RDS Instance** thông qua AWS Management Console.

- Hiểu quy trình kết nối ứng dụng hoặc Amazon EC2 đến Amazon RDS thông qua VPC và Security Group.

- Hiểu được các ưu điểm của Amazon RDS so với việc tự triển khai cơ sở dữ liệu trên EC2:
  - Tự động sao lưu (Automated Backup)
  - Tự động cập nhật và vá lỗi (Patch Management)
  - Khả năng mở rộng tài nguyên (Scalability)
  - Tính sẵn sàng cao (High Availability)

- Tìm hiểu về **Amazon DynamoDB** và mô hình cơ sở dữ liệu NoSQL trên AWS.

- Nắm được các khái niệm cơ bản của Amazon DynamoDB:
  - Table
  - Item
  - Attribute
  - Partition Key
  - Sort Key

- Biết cách tạo và quản lý bảng (Table) trong Amazon DynamoDB.
- Hiểu được sự khác biệt giữa cơ sở dữ liệu quan hệ (Amazon RDS) và cơ sở dữ liệu NoSQL (Amazon DynamoDB), từ đó biết lựa chọn dịch vụ phù hợp với từng bài toán.
