This section will list and introduce the blogs I have posted to [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj):

###  [Blog 1 - Secure Multi-Tenant RAG with Amazon Bedrock and Verified Permissions](3.1-Blog1/)
This blog introduces a multi-tenant document authorization solution for RAG architectures by combining Amazon Bedrock Knowledge Bases and Amazon Verified Permissions (Cedar policy language), optimizing infrastructure costs while delivering two-layer data security based on the Defense in Depth principle.

###  [Blog 2 - Automatically scale storage for Amazon RDS Multi-AZ DB clusters using AWS Lambda](3.2-Blog2/)
This blog presents an automated solution combining Amazon CloudWatch, AWS Lambda, and Amazon SNS to build an automatic storage scaling mechanism for RDS Multi-AZ Clusters as soon as the alert threshold is reached, helping to fill the Auto-scaling feature gap and minimize operational risks.

###  [Blog 3 - Building a Large-Scale Self-Managed RAG System with Amazon EKS and Amazon S3 Vectors](3.3-Blog3/)
This blog introduces a self-managed RAG architecture on Amazon EKS integrated with Amazon S3 Vectors and popular Open Source tools like Ray, Hugging Face TGI, and LangChain, helping to optimize large-scale vector storage costs and flexibility in model operations.
